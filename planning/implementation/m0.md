# M0 implementation sketch: foundations

M0 builds the pieces every later milestone stands on:
- the registry schema extensions;
- the result types;
- basis selection and rigorous ceilings;
- integer helpers;
- the independent verifier skeleton;
- the test infrastructure.

It ships no public algorithm. Exit criteria are in [../milestones.md](../milestones.md#m0-foundations-no-release).

Conventions in this sketch:
- **"Must"** marks a contract the tests enforce.
- Pseudocode is Python-flavored.
- `Fraction` is `fractions.Fraction`.
- Everything is pure Python with no required dependencies.

## Work order (one PR each)

| PR | Content | Why this order |
|---|---|---|
| 1 | Test infrastructure: markers, conftest, Hypothesis profiles, data loader, nightly workflow | every later PR uses it |
| 2 | Registry schema: structured domain, ceiling formula, `checked_against`; policy truth table | `_bases` reads the new fields |
| 3 | `results.py` | `_bases` and the verifier serialize results |
| 4 | `_intmath.py`, with naive cross-checks | independent of PRs 2–3; can run in parallel |
| 5 | `_bases.py`: `select_bases`, `ceiling_upper` | needs PRs 2 and 4 |
| 6 | `tests/verify/` skeleton and import lint | needs PR 3's plain-data format |

### Reference data (`tests/data/` and `tests/_data.py`)

File format: header lines, then the body.

```
# source: OEIS A006880
# url: https://oeis.org/A006880
# retrieved: 2026-11-26
# sha256: <hex of the body bytes, i.e. everything after the header block>
<body lines>
```

```
def load_data(name) -> list[str]:
    text = read tests/data/<name>
    header, body = split at first line not starting with "# "
    require keys {source, url, retrieved, sha256} in header
    require sha256(body bytes) == header.sha256
    return body lines
```

- A test runs `load_data` on every file in `tests/data/`.
- **Large data sets** are listed in `tests/data/remote.toml` (name, url, sha256, size) and fetched only by `fetch_data(name)` in `@slow` tests. They are cached in `~/.cache/corollarykit-tests/` and checked against the hash on every use.
- M0 commits one small **generated** file, `primes_below_100000.txt` (from our own sieve, plus a generator script), to exercise the mechanism. The OEIS files arrive with the milestones that need them. Values typed from memory are never committed.

## PR 2: Registry schema extensions

### New and changed fields in `bases.toml`

```toml
[bases.schoenfeld1976]
statement = "..."                       # human text, unchanged
domain = { ge = 2657 }                  # NEW: structured; keys ge, gt, le, lt (all ints, all optional)
domain_text = "x >= 2657"               # the old free-text domain, kept for docs
requires = []                           # NEW: preconditions the caller must ensure, e.g. ["odd_prime"]
ceiling = { kind = "sqrt_log", c = "22/25" }   # NEW, optional: see the ceiling kinds below
checked_against = ""                    # NEW: "Schoenfeld 1976, Cor. 1, p. 339 — checked by <name>"
transcription_checked = false
```

- **Domains** are structured, so `select_bases` can test them. Anything that isn't a numeric range (prime, odd, not a prime power) goes in `requires`. The caller must establish those conditions; the registry doesn't check them.
- **Ceilings** are named formula kinds with exact rational parameters, given as strings like `"22/25"`. **There is no `eval`.** The kinds are implemented in `_bases.py` (PR 5).
- **`checked_against`:** the loader **must** reject `transcription_checked = true` when `checked_against` is empty.

### Loader changes (`registry/__init__.py`)

```

load():
```

Also add `effective_status(basis, policy) -> Status | None`. It returns None when the policy rejects the basis, and otherwise the weaker of the basis's own status and its best accepted proof. `results.weakest()` uses it.

## PR 3: `results.py`

```
class Scope(Enum):
    FULL  = "full"      # checkable without trusting any basis
    BASIS = "basis"     # true if the named basis holds
    NONE  = "none"      # this claim is not made

PLAIN = int | str | bool | None | Fraction | tuple[PLAIN,...] | list[PLAIN] | dict[str, PLAIN]

def is_plain(obj) -> bool:
    recurse; bool and int allowed; float NOT allowed; dict keys must be str

@dataclass(frozen=True)
class Claim:
    name: str
    scope: Scope
    basis: str | None
    certificate: PLAIN = None
    def __post_init__:
        require (scope is BASIS) == (basis is not None)
        require is_plain(certificate)             # library objects never cross into tests/verify

@dataclass(frozen=True)
class Result(Generic[T]):
    value: T
    method: str
    claims: Mapping[str, Claim]                   # stored as MappingProxyType(dict(...))
    policy: str

    def weakest(self, policy: Policy) -> Claim | None:
        made = [c for c in claims.values() if c.scope is not NONE]
        if not made: return None
        key(c) = (0, effective_status(get_basis(c.basis), policy)) if c.scope is BASIS
                 else (1, CLASSICAL)               # FULL is strongest
        return min(made, key=key)

    def to_plain(self) -> dict:
        return {"value": plainify(value), "method": method, "policy": policy,
                "claims": {n: {"scope": c.scope.value, "basis": c.basis,
                               "certificate": c.certificate} for n, c in claims.items()}}

def compose(own_name: str, helper: Result, helper_claim: str) -> Claim:
    """Copy a helper's claim into the caller's result under a new name. Never merges claims."""
    c = helper.claims[helper_claim]
    return Claim(own_name, c.scope, c.basis, c.certificate)
```

`plainify(value)` handles ints, Fractions, tuples and dataclasses (field by field). Anything else raises `TypeError`, so unexpected types surface early.

**Tests:**
- A `Claim` with BASIS and no basis id, or with a float in the certificate, raises `ValueError`.
- `weakest()` orders FULL above BASIS, and among BASIS claims by effective status. It returns None when nothing is claimed.
- A `to_plain()` round trip through `json.dumps` with a Fraction-aware encoder.
- A Hypothesis test: random `is_plain` trees pass `to_plain` unchanged.

## PR 4: `_intmath.py`

Every function validates its arguments with `operator.index` and raises `TypeError` for non-integers. `bool` is rejected explicitly, because it is an `int` subclass.

### `small_primes(B) -> tuple[int, ...]`

```
_cache_limit = 1; _cache = ()          # module state; guarded by a lock for thread safety

def small_primes(B):
    if B < 2: return ()
    if B > _cache_limit: _resieve(max(B, 2 * _cache_limit, 2**16))
    return _cache[: bisect_right(_cache, B)]

def _resieve(N):                        # odd-only Eratosthenes, as benchmarked (π(10^8) in 0.66 s)
    s = bytearray([1]) * (N // 2 + 1)   # s[i] ↔ 2i+1
    s[0] = 0                            # 1 is not prime
    for i in range(1, (isqrt(N) - 1) // 2 + 1):
        if s[i]:
            p = 2i+1
            s[p*p // 2 :: p] = zeros(len(range(p*p//2, len(s), p)))
    _cache = (2,) + tuple(2i+1 for i where s[i] and 2i+1 <= N)
    _cache_limit = N
```

There is a hard cap on the cache (default 2²⁴, configurable). Above the cap, callers use `sieve_segment`.

### `sieve_segment(lo, hi) -> bytearray`

Flags for the **half-open (lo, hi]**: `flags[i]` ↔ n = lo + 1 + i, with 1 meaning prime.

```
def sieve_segment(lo, hi):
    require hi >= lo
    n0 = lo + 1; L = hi - lo
    flags = bytearray([1]) * L
    for n in range(n0, min(n0 + L, 2)): flags[n - n0] = 0      # 0 and 1 (and negatives) not prime
    for p in small_primes(isqrt(hi)):
        start = max(p*p, ceil_div(n0, p) * p)                   # never marks p itself
        flags[start - n0 :: p] = zeros(...)
    return flags
```

Memory is L bytes. Callers chunk large windows; a helper `iter_segments(lo, hi, chunk=2**20)` yields (seg_lo, seg_hi, flags).

### `progression_sieve(a, q, j0, j1, B) -> (flags, certain_below)`

Flags for v_j = a + j·q, j ∈ [j0, j1). A 1 means "no prime factor ≤ B, other than v_j itself being a prime ≤ B".

```
def progression_sieve(a, q, j0, j1, B):
    require q >= 1, gcd(a, q) == 1, 0 <= a < q (caller reduces), j1 >= j0
    flags = bytearray([1]) * (j1 - j0)
    for j in range(j0, j1): if a + j*q < 2: flags[j - j0] = 0
    for r in small_primes(B):
        if q % r == 0: continue                  # r ∤ v_j since gcd(a, q) = 1
        j_star = (-a) * pow(q, -1, r) % r        # v_j ≡ 0 (mod r)  ⇔  j ≡ j_star (mod r)
        first = j0 + ((j_star - j0) % r)
        flags[first - j0 :: r] = zeros(...)
        # restore r itself if it lies in the window (v_j == r is prime, not a multiple)
        if r >= a and (r - a) % q == 0:
            jr = (r - a) // q
            if j0 <= jr < j1: flags[jr - j0] = 1
    return flags, (B + 1) ** 2                    # survivors below this are certainly prime
```

Tests (edge cases from the testing plan): (2, 3) keeps 2; (3, 4) keeps 3; (5, 6) keeps 5; q = 1 keeps 2; and agreement with a naive per-element check for all q ≤ 60, a < q, a window of 200 and B ∈ {2, 10, 100}.

### `jacobi(a, n) -> int`

```
def jacobi(a, n):
    require n > 0 and n odd
    a %= n; result = 1
    while a:
        while a % 2 == 0:
            a //= 2
            if n % 8 in (3, 5): result = -result
        a, n = n, a
        if a % 4 == 3 and n % 4 == 3: result = -result
        a %= n
    return result if n == 1 else 0
```

### `iroot(n, k) -> (int, bool)`

```
def iroot(n, k):
    require n >= 0, k >= 1
    if n < 2 or k == 1: return n, True
    x = 1 << ceil_div(n.bit_length(), k)          # x ≥ true root
    while True:
        y = ((k - 1) * x + n // x**(k - 1)) // k   # integer Newton step, non-increasing from above
        if y >= x: break
        x = y
    return x, x**k == n
```

### `perfect_power(n) -> (r, e) | None`

This returns the **maximal** exponent: n = r^e, with r not itself a perfect power.

```
def perfect_power(n):
    require n >= 2
    for k in small_primes(n.bit_length()):        # n = t^e is a k-th power iff k | e (t not a power)
        r, exact = iroot(n, k)
        if exact:
            sub = perfect_power(r) if r >= 4 else None
            return (sub[0], k * sub[1]) if sub else (r, k)
    return None
```

### `trial_divide(n, B) -> (dict[int, int], int)`

```
def trial_divide(n, B):
    require n >= 1
    factors = {}
    for p in small_primes(B):
        if p * p > n: break
        while n % p == 0: factors[p] += 1; n //= p
    if 1 < n <= B: factors[n] += 1; n = 1         # leftover small prime
    return factors, n
```

Postcondition: the cofactor has no prime factor ≤ B, and if 1 < cofactor < (B+1)², the cofactor is prime. The docstring states this. Callers that need primality still go through `prove_prime` (M3), unless the cofactor is below that bound.

### `prime_count_exact(x, *, backend="auto") -> int`

```
def prime_count_exact(x, backend="auto"):
    if x < 2: return 0
    if backend in ("auto", "primecount") and primecount importable:
        return primecount.pi(x)
    if backend == "primecount": raise ImportError
    # pure Python: segmented odd-only sieve, chunks of 2^20 odd numbers
    count = 1                                     # the prime 2
    for (seg_lo, seg_hi, flags) in iter_odd_segments(1, x):
        count += flags.count(1)
    return count
```

The pure-Python path must be exact for every x. Its speed sets the `exact_limit` default in M2, not here.

## PR 5: `_bases.py`

### `select_bases(policy, candidate_ids, x) -> list[Basis]`

```
def select_bases(policy, candidate_ids, x):
    """The accepted bases, among candidate_ids, whose numeric domain contains x, in the caller's
    preference order. Preconditions in `requires` are the caller's responsibility."""
    out = []
    for bid in candidate_ids:
        b = get_basis(bid)                         # unknown id → KeyError (a bug, not a policy matter)
        if policy.accepts(b) and b.domain.contains(x): out.append(b)
    return out
```

The order is the caller's choice, because "strongest" depends on the input. For x ≥ 10¹², for example, Schoenfeld beats Dusart. Functions list their candidates in preference order. Where two bases both apply to an interval, the caller intersects them.

### `ceiling_upper(basis, **inputs) -> int`

Returns an integer **≥** the true value of the basis's ceiling formula at the inputs. It uses only exact rational arithmetic.

**Rational upper bound for ln:**

```
LN2_UP = Fraction(69314718056, 10**11)             # > ln 2 = 0.693147180559945...

def ln1p_upper(t: Fraction) -> Fraction:
    """Rational upper bound on ln(1+t), for 0 ≤ t < 1.
    ln(1+t) = 2·artanh(u) = 2·Σ u^(2i+1)/(2i+1), with u = t/(2+t) ≤ 1/3.
    Take K terms, then bound the tail by a geometric series:
        tail ≤ 2·u^(2K+1) / ((2K+1)·(1 − u²))."""
    u = t / (2 + t)
    s = sum(Fraction(2, 2*i + 1) * u**(2*i + 1) for i in range(K))       # K = 8
    tail = 2 * u**(2*K + 1) / ((2*K + 1) * (1 - u*u))
    return s + tail                                                       # error ≤ ~1e-9

def ln_upper(n: int) -> Fraction:
    """A rational U with U ≥ ln n, for n ≥ 1."""
    require n >= 1
    b = n.bit_length()                             # 2^(b-1) ≤ n < 2^b
    base = 1 << (b - 1)
    t = Fraction(n - base, base)                   # n = 2^(b-1) · (1 + t), 0 ≤ t < 1
    return (b - 1) * LN2_UP + ln1p_upper(t)
```

The overshoot is at most about 1e-9 + 4·10⁻¹²·b in absolute terms. The naive version, ln(1+t) ≤ t, would overshoot by up to 0.31, which is a 1.4 % relative error at n = 2³². It is rejected for that reason. To keep the arithmetic cheap, limit the denominators: round each term of the sum up to a fixed denominator 2⁶⁴ before adding.

**Ceiling kinds.** All of them are increasing in every input, so substituting upper bounds gives upper bounds:

```
def sqrt_upper_fraction(x) -> Fraction:        # ≥ √x, within 2^-64
    s = isqrt(x << 128)
    return Fraction(s if s*s == x << 128 else s + 1, 2**64)

CEILING_KINDS = {
  "log_pow":     lambda p, n:      p.c * ln_upper(n) ** int(p.k),                  # c·(ln n)^k
  "sqrt_log":    lambda p, x:      p.c * sqrt_upper_fraction(x) * ln_upper(x),     # c·√x·ln x
  "qlogq_sq":    lambda p, q:      p.c * (q * ln_upper(q)) ** 2,                   # c·(q ln q)^2
  "phiqlogq_sq": lambda p, q, phi=None:
                     p.c * ((phi if phi is not None else q - 1) * ln_upper(q)) ** 2,
                                     # φ(q) ≤ q − 1 for q ≥ 2 gives a valid bound when φ isn't supplied
}

def ceiling_upper(basis, **inputs):
    require basis.ceiling is not None
    f = CEILING_KINDS[basis.ceiling.kind]          # unknown kind → error at import-time validation
    value = f(basis.ceiling.params, **inputs)      # Fraction
    return ceil(value)                             # Fraction → int, rounding up
```

At import time, check that every `ceiling.kind` in the registry exists in `CEILING_KINDS` and that each has the parameters it needs. A mismatch fails at import, not at first use.

### Tests (`tests/test_bases.py`)

- **Soundness:** `ln_upper(n) ≥ ln n` and `ceiling_upper(...) ≥` the true formula, for 10⁴ random n up to 2⁴⁰⁹⁶, plus n ∈ {1, 2, 3, 2^k, 2^k ± 1}. The true values come from `mpmath` at 3× working precision, compared as exact rationals with mpmath's error bound taken into account. `oracle_flint` adds an Arb cross-check.
- **Tightness:** for n ≥ 2¹⁶, `ln_upper(n) − ln n < 10⁻⁸`, and `ceiling_upper` is within 0.01 % + 2 of the true value. This catches an accidentally loose implementation.
- **`ln1p_upper` soundness:** at t ∈ {0, 1/2, 1 − 2⁻⁶⁴} and 10³ random rationals in [0, 1), the result is ≥ mpmath's ln(1+t) and exceeds it by less than 10⁻⁸.
- **`select_bases`:**
  - respects the domain edges (2656 and 2657 for `schoenfeld1976`, using a test policy with `allow_unchecked_transcriptions`);
  - returns `[]` under `DEFAULT` while every transcription is unchecked;
  - preserves the caller's order.
- **Registry validation:** every registry ceiling kind exists, and an injected unknown kind fails validation.

### The import lint (`tests/test_verify_independence.py`)

```
ALLOWED = {"corollarykit.registry"}

for path in glob("tests/verify/**/*.py"):
    tree = ast.parse(read(path))
    for node in ast.walk(tree):
        names = []
        if Import:     names = [alias.name for alias in node.names]
        if ImportFrom: names = [node.module] if node.level == 0 else []   # relative imports are fine
        for name in names:
            if name == "corollarykit" or (name.startswith("corollarykit.")
                                          and not any(name == a or name.startswith(a + ".") for a in ALLOWED)):
                fail(f"{path}:{node.lineno} imports {name}")
    forbid dynamic import: any Call to importlib.import_module or __import__ → fail
```

A second test proves the lint works. It writes a temporary file in `tests/verify/` that imports `corollarykit._intmath`, runs the lint, asserts that it fails, and deletes the file.

**Rule for `corollarykit/__init__.py`:** since `import corollarykit.registry` runs the package `__init__`, it must stay limited to the registry and the error types. A test asserts that importing `corollarykit.registry` loads no other `corollarykit.*` modules, by checking `sys.modules` in a subprocess.

## Implementation notes (M0 as built)

Where the code departs from the sketch above:

- **√x in the `sqrt_log` ceiling** uses `sqrt_upper_fraction`, a rational within 2⁻⁶⁴ of √x, not ⌈√x⌉. Rounding √x up to an integer first overshoots by about c·ln x: 0.4 % at x = 2¹⁶, which failed the tightness test.
- **The time budget** can be configured with `COROLLARYKIT_TIME_BUDGET` (seconds; default 60) and disabled with `COROLLARYKIT_NO_TIME_BUDGET=1`. `tests/test_infra.py` checks that the hook fails the run.
- **`prime_count_exact`** has only the pure-Python backend. `backend="primecount"` is wired up in M2, once the bindings and their API are chosen.
- **Generated data** (`primes_below_100000.txt`, `policy_snapshot.txt`) comes from `tests/data/regen.py`. `tests/test_data.py` fails if either file is stale.
- **Integers beyond 64 bits in domains** (Sorenson–Webster's bound) are written as strings in TOML.
